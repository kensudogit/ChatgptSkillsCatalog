# BOM コストレビュー

電子部品の BOM（部品表）を読み、コスト・代替品・調達リスクを整理する Skill です。

## 確認項目

1. 営業部品と非営業部品を区分する
2. 単価・MOQ・納期が実績に対応しているか
3. 代替品（ピン互換 / 電気仕様）の有無
4. 営業終了・長納期・単一序列のリスク
5. 幣種・注文単位・運賃を含めた総コスト

## 出力形式

- 高コスト部品トップ 5
- 代替案（理由付き）
- 調達リスクの優先度
