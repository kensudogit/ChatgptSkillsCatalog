# はんだ付け工程 QA

リフロー / 流動はんだ付けの工程品質を確認する Skill です。

## 確認項目

1. リフロープロファイル（上昇 / ピーク / 冷却）が部品要件内
2. パスト印刷の厚み・アパーチャ・クリーニング
3. 橋の小屋 / ボイド / 心偏せ / 未はんだ
4. フラックス残留と清洗要否
5. AOI / X線 / 外観検査の合否基準

## 出力

不合モードごとに原因仮説と映像を整理する。
