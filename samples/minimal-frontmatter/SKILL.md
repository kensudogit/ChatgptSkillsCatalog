# 最小 frontmatter

Agent Skills で必須なのは `name` と `description` です。

version / author / category / tags は省略可能です（カタログ表示は空になります）。

## 使い方

この Skill を開いて、最小構成でも Claude / ChatGPT / Cursor に読み込まれることを確認してください。
