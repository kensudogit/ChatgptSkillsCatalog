# PCB 設計チェックリスト

PCB 設計レビューの確認項目を指導する Skill です。

## チェックリスト

1. ランド / クリアランスが社内設計規則に合致している
2. デカプリングコンデンサが電源ピン近傍にある
3. 高速信号のインピーダンス制御・長さ整合
4. サーマルビア / 銀面積が熱設計要件を満たす
5. シルク / 極性表示が読み取れる

## 使い方

レビュー対象の設計情報を提示し、上記チェックリストに照らして指摘を整理してください。
